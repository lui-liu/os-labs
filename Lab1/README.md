# Лабораторная работа №1

## Вариант 13
Родительский процесс создаёт два дочерних процесса. Родитель принимает от
пользователя строки и пересылает их в pipe1. Child1 переводит строки в нижний
регистр и передаёт child2 через pipe3. Child2 превращает все пробельные символы
в «_» и пересылает результат родителю через pipe2. Родитель выводит результат
в стандартный поток вывода.

## Сборка

### С помощью make
```bash
make
```

Удалить собранные программы:
```bash
make clean
```

### Вручную
```bash
gcc -Wall -Wextra -o parent parent.c
gcc -Wall -Wextra -o child1 child1.c
gcc -Wall -Wextra -o child2 child2.c
```

Важно: исполняемые файлы должны называться именно `child1` и `child2`
и лежать в одной папке с `parent`, иначе родитель не сможет их запустить.

## Запуск
Запускать из папки Lab1 (дочерние программы ищутся в текущей папке):

```bash
./parent
```

Вводите строки. Выход: пустая строка или Ctrl+D.

### Пример
```
$ ./parent
Hello WORld! I'm NOT a ChIlD    OkaY?!
hello_world!_i'm_not_a_child____okay?!
```
