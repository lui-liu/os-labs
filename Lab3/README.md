# Лабораторная работа №3

## Вариант 13
Задание первой лабораторной работы, переделанное на **shared memory** и
**memory mapping** вместо каналов. Родительский процесс принимает от
пользователя строки и передаёт их дочерним процессам через общую память.
Child1 переводит латинские буквы в нижний регистр. Child2 заменяет пробельные
символы на «_», сохраняя переводы строк (`\n`) и пустые строки. Родитель
выводит результат в стандартный поток вывода.

## Как это устроено
- Родитель создаёт именованный shared memory объект (`shm_open`), задаёт его
  размер (`ftruncate`) и отображает в память (`mmap`). Дети открывают тот же
  объект по имени и тоже отображают его.
- Синхронизация: три именованных семафора (`sem_open`), все со значением 0.
  Они передают «ход» по цепочке parent → child1 → child2 → parent:
  процесс ждёт свой семафор (`sem_wait`), работает с общей памятью и
  поднимает семафор следующего (`sem_post`).
- Имена shared memory и семафоров содержат PID родителя
  (`/lab3-shm-<pid>`, `/lab3-sem1-<pid>` и т.д.), поэтому разные запуски не
  пересекаются. Дети получают имена через аргументы командной строки.
- Конец ввода передаётся специальным значением длины (`STOP_MARKER`).
- При ожидании обработанной порции родитель проверяет дочерние процессы
  после каждого истечения таймаута. При EOF он ждёт завершения обоих
  процессов, проверяет их коды возврата и подтверждение от child2.
- При обнаруженной ошибке родитель останавливает оставшиеся дочерние процессы
  и удаляет объекты, созданные этим запуском.

## Сборка

### С помощью make
```bash
make
```

Удалить собранные программы:
```bash
make clean
```

### Вручную
```bash
gcc -Wall -Wextra -o parent parent.c
gcc -Wall -Wextra -o child1 child1.c
gcc -Wall -Wextra -o child2 child2.c
```

Исполняемые файлы должны называться `child1` и `child2` и лежать в одной
папке с `parent`. На системах со старой glibc (до 2.34) к командам нужно
добавить `-pthread -lrt`.

## Запуск
Запускать из папки Lab3 (дочерние программы ищутся в текущей папке):

```bash
./parent
```

Вводите строки. Выход: Ctrl+D (конец ввода).

### Пример
```
$ ./parent
Hello WORld! I'm NOT a ChIlD    OkaY?!
hello_world!_i'm_not_a_child____okay?!
```

## Если программу прервали по Ctrl+C
Объекты прерванного запуска могут остаться в `/dev/shm`. После завершения
процессов укажите PID родителя этого запуска и удалите его объекты:
```bash
pid=12345
rm -f "/dev/shm/lab3-shm-$pid" "/dev/shm/sem.lab3-sem1-$pid" \
      "/dev/shm/sem.lab3-sem2-$pid" "/dev/shm/sem.lab3-sem3-$pid"
```
